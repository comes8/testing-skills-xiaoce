# 资金专项核对与输出

按任务输出资金流、账户/科目关系、核对轨迹、专项测试点或已有点的评审。每个数值都有资产、账户、阶段、来源与计算前提，不以一个总余额替代全链路。

## 建议核对表

| 信息 | 核对内容 |
|---|---|
| 业务与资产 | 业务 ID、资产唯一身份、链/代币与币种、账户及归属 |
| 状态和资金腿 | 请求、冻结、在途、源/目标、链上阶段和最终结算，各自的已知语义 |
| 金额轨迹 | 期初、每项实际增减、费用、重分类、期末、差额；未知项不伪填0 |
| 独立证据 | 来源、业务键、全部真实效果、事件时点与切点，不把同源返回当独立真值 |
| 测试点 | 目标、条件/顺序、允许/禁止结果、规则/准备状态、优先级理由 |
| 未决项 | 规则冲突、阶段边界、观察或控制不足、对哪些分支有影响 |

不必每次填满所有表。窄范围只给相关差异，保留原 SRC/RUL/ISS/TP 标识；新增与修改分开，重复 ID 按原位置显式映射。

## 对账算法边界

固定统计范围、资产、账户与一致切点，再用实际经济效果解释期末。内部重分类不当外部收入，费用内扣/外加不能双扣，在途不漏算也不重复算。多币种、用户负债与平台资产需要各自模型。

全部真实资金记录保留并按科目含义核算。不能按业务 ID 先删重复记录，也不能把一笔业务的合法多行借贷腿都算成重复效果；净额正确仍需检查禁止的中间行为。

独立计算与被测结果分开，以 Decimal 或最小单位整数处理精度，明确逐笔或累计舍入。源/目标/链证据应对齐同一业务截面；跨时点短暂不一致与最终差错分别定性。

## 交付结论

每点说明可固定预期和待决部分。即使源业务已明确，缺少独立流水或链证据也不能宣称执行就绪；观察能力不足不反过来改写已知规则。未知费率、补偿、重组或保留期不选一个常见方案补齐。

独立变体分开判定和留证，不用一个结果代表整点。没有实际运行时只给设计与核对判断，不能说已在真实系统复现资金缺陷。本 Skill 无需其他技能或平台依赖，也不执行真实资金操作。
