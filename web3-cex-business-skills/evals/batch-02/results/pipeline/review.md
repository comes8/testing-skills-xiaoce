# B2-01 两个实际产物的自评

本次只把 `evals/batch-02/cases/01-spot-cancel.md` 的 SRC-201～203 作为业务事实依据，复核已写出并读回的 [01-model.md](01-model.md) 与 [02-testpoints.md](02-testpoints.md)。未读取验收答案、其他案例或其他代理结果。以下是设计产物自评，不是实现执行结果。

## 结论：局部不通过，不能无条件交接为执行判据

模型的核心数量、金额和分阶段关系未发现确定性实质错误；测试点 TP-210 有一处会改变判定的时序表述缺陷，另有轻微编号追溯问题。已保留原产物，以下记录缺陷与应改方向；本自评没有把“整体方向正确”当作全部通过。

## 实际问题

### RV-01：TP-210 对处理中重复通知的金额截面写得过强（中等，需改）

- **位置**：`02-testpoints.md` 第 85～86 行。条件同时包含“首轮处理尚在进行”和“已经完成后重复”，预期却写“重复前后累计取消释放只能是 30 Q”。
- **原文依据**：SRC-202 允许 CANCELED 的资金暂为 PENDING，并要求从取消实际生效起 2 秒内完成；同一结算事件重复通知不能重复释放资金。它没有要求首轮处理未完成时累计取消释放已经达到 30 Q。
- **反例**：首轮尚在 PENDING，取消释放仍为 0 Q；此时重复通知到达，随后在 2 秒内只产生一次总计 30 Q 的有效释放。此过程可符合源文，却可能被“重复前后只能是 30”误判失败。TP-209 本身已正确允许这一中间状态，因而产物内部也出现潜在冲突。
- **应改方向**：分开两个观察阶段。处理中重复：核对重复没有制造额外释放，待处理完成后累计释放为 30 Q、最终 981/0 Q；完成后重复：重复前后最终金额和累计释放均保持不变。处理中不强制某一未定义的中间金额。并发在途与完成后重放至少须分别写明条件和判据，可以保留为同一点的两个子分支。
- **影响范围**：这是测试点交接阶段的局部退化；模型 INV-206 没有要求处理中已释放满额，不需要据此推翻模型或其他资金计算。

### RV-02：测试点共用基线使用未定义的缩写编号（低，需清理）

- **位置**：`02-testpoints.md` 第 8～9 行的 T05/T09/T10、T06/T07，以及部分准备项里的 E04 等缩写。
- **问题**：正式编号是 TP-205、TP-209、TP-210、TP-206、TP-207 与 ISS-E04；缩写含义可猜，但不符合稳定交接标识。不能把 T05 当作一个实际存在的正式 ID。
- **应改方向**：统一使用完整既有 ID，不重编号。它不改变业务规则，但影响机器或人工追溯。

## 已核对成立的关键内容

| 依据与风险 | 对两个产物的实际判断 |
|---|---|
| SRC-201 固定资金样例 | 模型 950/50 → 951/30 → 981/0 Q 正确；消费 19、成交价差 1、取消释放 30 已分开。TP-204 没有只检查最终值，能够发现价差延迟释放。十进制独立重算一致。 |
| SRC-201 数量口径 | INV-201 与 TP-205 保留 f=2、u=3、a=0、c=3；没有将未成交量随活动量一起清零。逻辑口径未冒充实际接口字段。 |
| SRC-202 受理/生效 | MOD-203、TP-205 没有由 accepted=true 推定取消或解冻完成；TP-206 的额外成交在实际生效前，符合给定允许窗口。 |
| SRC-202 竞争顺序 | TP-206、207、208 分别固定额外部分成交先、全成先和取消先；没有把 FILLED/CANCELED 任一结果均算通过。变体金额 972、951 Q 与实际追加成交量价相符，且未冒充固定样例。 |
| SRC-202 订单与资金阶段 | 模型与 TP-209 允许 CANCELED+PENDING，没有以 a=0 推定资金已为零，也没有强制必须看到 PENDING。TP-210 的局部措辞问题除外。 |
| SRC-202 2 秒期限 | INV-205、TP-209 使用实际取消生效和结算事件时刻；没有把首次轮询当起点。读取通道未提供被记为执行能力缺口，而不是把 2 秒规则改为待确认。 |
| SRC-202 通知与独立来源 | E-QTY、E-FUND 与 TP-208、210 区分真实执行/记账效果和通知条数；没有要求一事件一流水行，也没有用查询=WS 证明资金正确。 |
| SRC-203 边界 | 未发明 API、错误码、最大量、重试保留期或恢复算法；没有执行交易、改平台或宣称已有观测能力。 |

## 遗漏、混淆与规模判断

- **未发现关键源规则完全漏掉**。数量下限/步长、消费和价差、三种数量口径、三条关键竞争路径、独立资金完成、真实 2 秒起止、同事件重复释放都能找到具体判据。这个结论基于逐条回查，而不是基于十个测试点的数量。
- **没有把主要观察缺口写成规则缺口**。实际仲裁读取、两个实际事件时刻、独立流水与重放能力仍属 ISS-E 系列；最大量、异参重试等未给语义属 ISS-R 系列。PENDING 的精确中间资金过程可以保留为局部规则问题，但不能拿它阻塞已知最终金额/SLA；TP-209 已说明这一点。
- **实际展示值的验证仍有限**。原文的 u/a/c 是逻辑口径而非已知接口字段，当前可定义逻辑预期，但没有证据证明可以读取并对比对应实现值。产物已注明能力待核对；后续不能把仅按定义重建的值宣称为“已验证平台字段正确”。这属于执行限制，不是当前模型算错。
- **篇幅有可压缩处**。模型把相同的受理/生效与来源独立性分别写进规则、节点、状态和交接表；测试点也重复强调能力未证实。可保留首次完整解释，后面只引用编号。没有扩到全交易所、所有账户模式或完整异常框架，但当前文字量仍高于这条局部需求的最小交接规模。

本批没有证据支持报告“实现通过”。修正 RV-01、统一 RV-02 后，可交付为评审设计；真实执行仍须补齐原始材料已经指出的观察和控制能力。
