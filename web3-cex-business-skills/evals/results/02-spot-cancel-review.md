# 现货部分成交后撤单：评审问题与建议补充条款

以下仅评审合成材料。准备程度为**可部分继续**：撤单不改变已发生成交可以继续作为草案设计依据；字段口径、版本切换和释放完成判据存在局部阻塞。所有问题均为文档问题或待核实风险，没有代码及运行证据，不能报告为已复现软件缺陷。

## 评审问题

| ID / 严重程度 | 位置与问题 | 业务影响、待决策内容及阻塞范围 |
|---|---|---|
| ISS-001 / 阻塞性（字段及资金预期） | SRC-A，PRD 草案 v2 §4.2，案例 02 第 12 行：`remainingFrozen` 在撤单终态后为 0。SRC-B，接口文档 v1 字段说明，第 20 行：同名字段是下单时冻结额度，撤后不更新，实际冻结查账户资金接口。两者对字段时间语义存在冲突 | 直接用该字段判断释放会把历史冻结值当剩余冻结，或破坏旧客户端。需产品与接口维护方确认目标接口版本及字段口径、保留旧字段/新字段/版本化的方案，以及新旧客户端和历史订单的解释。不能自行裁定 v1 或 v2 优先；阻塞这个字段的最终数值与兼容预期，不阻塞“撤单不改已发生成交” |
| ISS-002 / 阻塞性（终态观察） | SRC-B 第 19 行仅说明 `accepted=true` 是接收；SRC-A 第 12、14 行未给撤单终态判据或账务释放先后。SRC-C 已有分析第 25–26 行却认定响应成功即取消，且 100 毫秒后所有余额一致 | 受理后仍可能有成交竞争或尚未撤销，错误使用响应可能提前认为剩余委托消失或资金已释放。需明确哪个观察源/状态代表订单取消、哪些资金状态可过渡、最终释放条件、起算点和业务认可时限；删除或更正 SRC-C 的无据结论。阻塞最终冻结观察窗口与异步验收，不能自造等待时间 |
| ISS-003 / 阻塞性（版本边界） | SRC-A 第 13–14 行拟将步长改为 0.01；SRC-B 第 18、21 行仍为 0.001，缺版本切换说明 | 这是新目标与旧文档的差异，未必代表同一版本实现错误。需确认新步长何时对哪些入口、客户端和订单生效，发布前按旧步长接受的在途订单如何成交/撤销；例如旧单数量 1.001 不能无依据按新步长判非法或改写。阻塞跨版本和存量订单预期，不妨碍分别记录两版本资料各自明示的步长 |
| ISS-004 / 重要 | SRC-C 第 25–26 行宣称“接口 v1 优先于其他资料”，没有优先级决策来源 | 若以该断言消解冲突，会把草案目标吞并为旧行为。需由项目决策明确版本/批准状态/适用范围并同步相关材料。当前只可保留双方依据及冲突，不能把草案当已批准或把接口文档当实际运行证明；阻塞冲突项的单一硬性验收口径 |
| ISS-005 / 重要 | SRC-A 第 11 行虽明确撤销剩余量、不变更已成交量，但未给撤单与后续成交竞争的裁决和终态说明 | 需分别明确成交先完成、撤单先完成、撤单处理期间又部分成交时，哪些成交已生效、剩余量何时停止撮合、撤单可能得到什么最终结果。否则可能把合法追加成交误报成撤单失败，或漏掉终态后继续成交。具体状态枚举与裁决点待产品和研发提供，不自行增加状态名 |

## 建议补充条款（建议稿，均待项目确认）

1. **字段与版本条款，对应 ISS-001/004。** 分别列出 v1 当前文档口径与 v2 拟议口径、目标适用接口版本及生效范围。若决定保留历史冻结字段，应明确其不用于判断剩余释放，并给出实际剩余冻结的目标观察源；若决定让原字段动态归零，必须给出版本隔离或兼容方案。发布前由项目确认选择，再据此同步 PRD、接口与旧分析，不能在这里代选。

2. **受理、终态与资金条款，对应 ISS-002。** `accepted=true` 只表示请求接收，不能据此判断取消或账务完成。请补充订单取消终态的正式判据；发生该终态时，说明剩余委托是否已停止撮合、实际冻结是否同时释放，若允许异步，明确资金完成条件、起算点、允许中间态及最大业务时限。PRD v2 所写目标字段终态后为 0 与资金真实释放的关系也须一并明确。未确认前不得保留“等待 100 毫秒后所有余额必定一致”的断言，也不能用固定睡眠替代完成判据。

3. **步长及在途适用条款，对应 ISS-003。** 明确 v2 的 0.01 步长适用对象及切换时点；对不符合该步长的新请求按已明示目标拒绝，具体拒绝结果及业务副作用需补充。对发布前依 v1 的 0.001 步长接受的订单，明确保留原规则、转换或其他选定处理及用户影响；不得未经决策静默取整或让原有合法订单无法撤销。0.01 的合法性应按精确十进制/整数最小单位判断；资料没有最小量、最大量和具体价格/费用规则，不额外设定。

4. **部分成交及竞争条款，对应 ISS-005。** 重申已发生的成交不因撤单减少（SRC-A 第 11 行，草案明示）。以项目确定的事件先后及裁决点区分成交先完成、撤销剩余量先完成和处理中又部分成交；最终累计成交须能由实际成交明细解释，只有最终未成交的剩余量被取消。订单终态和竞态返回由项目补全后才固定为验收预期，不以受理响应替代。

5. **关联与核对条款，对应 ISS-006/002。** 为本订单列出订单/成交/资金流水的真实关联字段及可用观察源，基于初始冻结、实际成交资金消耗、按项目规则计入冻结的费用和其他已确认调整，核对本订单应释放与最终剩余冻结。公式、币种、精度、舍入时点和中间态允许范围需有来源；当前不提供数字金额。单一被测资金接口返回或两个同源读模型一致不能作为完整独立证明；缺独立证据时标明盲区。

6. **修订既有分析条款，对应 ISS-002/004。** 将 SRC-C 的“响应成功即取消”“100 毫秒全部一致”“接口 v1 优先”改为上述已有依据与待确认项；保留其来源位置以便复审。本次不把这些文档断言判为真实系统故障。
